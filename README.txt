PRIME X — JEE Study Planner
============================

1. Extract the ZIP.
2. Open the PRIME-X folder in VS Code.
3. Double-click index.html OR use VS Code Live Server.
4. Everything works locally; data is stored in browser localStorage.

Source:
Built around the uploaded "Syllabus for JEE (Main) - 2026", Paper 1 (B.E./B.Tech.), Mathematics, Physics and Chemistry.
The Paper 2 sections in the PDF are intentionally not included in the JEE Paper 1 planner.
